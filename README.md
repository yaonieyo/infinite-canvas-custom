# 无限画布定制版

这是基于原有无限画布项目持续定制的个人工作流版本，主要服务于真人情感短剧的剧本分析、分镜设计、故事板制作、参考资产管理，以及图片和视频提示词生成。

项目保留原有的无限画布、节点和连线机制，在此基础上增加了面向短剧创作的分镜工作流。

## 项目定位

这个仓库保存的是无限画布的代码版本和功能修改记录，方便：

- 查看当前项目代码
- 追踪每次功能更新
- 在出现问题时回退到旧版本
- 在其他电脑上恢复项目代码
- 继续开发新的分镜和生成工作流

## 当前功能

- 无限画布、节点和连线工作流
- 图片、视频、上传和生成节点
- 剧本拆解与故事板工作流
- 导演标注九宫格、十二宫格故事板
- 彩色写实九宫格、十二宫格分镜图
- 图片提示词与视频提示词转换
- 角色、场景等参考资产管理
- 镜头资产收集与绑定
- 参考图传递和生成提示词组织
- 节点删除、画布布局和交互优化
- Git 版本管理与历史回退

## 故事板工作流

项目支持将剧本或详细分镜整理为可执行的视觉方案，重点关注：

- 人物关系和空间位置
- 景别、机位、构图和视线方向
- 动作、停顿和情绪推进
- 前景、中景、后景及遮挡关系
- 人物、服装和场景的连续性
- 故事板图片与后续视频提示词的一致性

导演标注版本使用黑白分镜草图，并通过彩色标注区分人物动作、摄影机运动、构图、光线和情绪重点；彩色写实版本用于更直观地预览镜头画面。

## 生成接口

项目可以连接本地配置的图片、视频和文本生成接口。具体使用哪些模型、接口地址和参数，以本机的 API 配置为准。

仓库不会公开个人密钥，也不会把密钥直接写入代码。

## Git 仓库与完整备份的区别

GitHub 仓库主要保存代码、页面和功能修改，体积较小，适合版本管理和更新。

本地完整备份则用于恢复当前电脑上的完整工作环境，可能包含本地运行文件、依赖、数据、资产和历史内容，因此体积会明显更大。

## 不上传到 GitHub 的内容

为了避免泄露隐私、密钥和大量生成文件，以下内容默认排除在 Git 之外：

- API 密钥和环境变量
- 本地项目数据
- 角色、场景和服装资产
- 生成的图片和视频
- 日志、缓存和临时文件
- 本地备份和运行时依赖

因此，从 GitHub 下载代码到其他电脑后，需要重新准备本地运行环境，并重新配置 API、数据和资产。
